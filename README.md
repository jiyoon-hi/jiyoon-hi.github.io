# Minimal academic website for GitHub Pages

A lightweight, minimal academic homepage template in plain HTML and CSS.

## Launch
1. Create a public GitHub repository named `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html`, `research.html`, `projects.html`, `style.css`, and the `assets/` directory to the repository's root (not the enclosing folder).
3. In repository Settings → Pages, choose **Deploy from a branch**, branch `main`, folder `/(root)`, and Save.
4. Visit `https://YOUR-GITHUB-USERNAME.github.io` after GitHub Pages publishes.

## Customize
- Replace `Your Name`, bio, email, links and publication placeholders.
- Add your actual photo as `assets/profile.jpg`, then change the `<img>` in `index.html` to reference it.
- Put your CV PDF at `assets/cv.pdf` (or remove CV links until ready).
- Change colors, widths and typography in `style.css`.
- Links containing `href="#"` are placeholders, not functioning resources: replace them with your real paper/project links.
- Keep personal details and claims accurate before publishing.
